📈 Featured Project

Superstore Sales Performance Dashboard

An end-to-end data analytics project using the Superstore dataset to analyze sales performance, profitability, regional performance, product categories, and monthly sales trends.

Tools used: Power BI, Power Query & Excel

🔍 Key Analysis

* Total Sales and Total Profit performance
* Sales performance by region
* Sales performance by product category
* Monthly sales trends
* Profit by region
* Profit Margin analysis
* Relationship between sales and profitability

📊 Project Results

* Total Sales: $2.3M
* Total Profit: $286.4K
* Total Orders: 5,009
* Profit Margin: 12.47%
